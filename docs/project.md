- 工作区初始化与 Run 创建不依赖第三方包，见 README.md。
- 业务自动化框架、脚本命令及依赖：待实际选型和验证，当前未配置。

- 浏览器 UI 测试需用户主动提出；不得因任务涉及页面就自行启动。
