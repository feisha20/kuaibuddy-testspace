# KuaiBuddy 已确认测试知识

当前没有已确认的项目测试经验。本文件不收录设计方案里的演示业务，也不把初始化检查当作业务经验。

新增条目前先核对正式资料、可追溯证据及适用条件，并由工程师确认。未确认观察、排查猜测和原始日志保留在本次 Run。

## 知识条目模板（不是已确认知识）

```markdown
## K-<唯一编号>：<标题>
- 类型：风险经验／已知缺陷／排查经验／测试策略
- 验证状态：已确认
- 适用模块与版本：<填写>
- 适用条件：<触发条件与边界>
- 结论或建议：<可复用内容>
- 依据：<正式资料、可访问的缺陷链接、受控证据归档及必要 Run 标识>
- 关联任务／用例：<仓库内路径或编号>
- 确认人：<填写>
- 最近核对日期：<YYYY-MM-DD>
- 失效条件或复核提示：<版本、规则变更等>
```

其他成员无法直接访问本机 `.runtime/`。用于共享知识的关键依据应提供脱敏摘要或受控归档引用；失效条目保留编号并标记失效及替代条目。
