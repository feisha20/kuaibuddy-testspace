# KuaiBuddy 本地任务执行

按仓库 AGENTS.md 读取相关项目事实、知识、任务和用例。本技能组织运行记录，不实现登录或接口客户端；按实际可用性选择获授权工具，缺少工具时报告缺口。

1. 核实环境、版本、角色、正式预期和允许操作范围。缺失前置条件的用例标记阻塞，继续可独立工作。
2. 按 README.md 创建独立 Run：UTC 时间戳加随机后缀，创建时禁止覆盖。复制 assets/ 下三个模板，替换 TASK_ID 和 RUN_ID。
3. 在 plan.md 记录范围、依据、数据、版本、工作树状态和任务差异；execution.md 只记录真实动作及时间，不预填成功。
4. 对话逐轮等待完成，保存真实响应和实际可获取的关联标识；接口按正式契约核对响应及业务副作用。未获取字段明确标注，不能编造。
5. result.md 分别统计通过、失败、阻塞、未执行，逐项列出依据与证据，推断标为待验证。创建 Run 或命令退出成功不等于业务通过。
6. 提出资产沉淀建议，工程师确认前不将运行观察写成项目知识；已有明确资产更新授权时按范围执行。

## 模板与交付
- [计划模板](assets/plan.md)：本次范围和前置条件。
- [执行模板](assets/execution.md)：实际动作和证据索引。
- [结果模板](assets/result.md)：真实结果与限制。
- 脱敏日志保存至 logs/，获授权截图至 screenshots/，报告和其他产物至 artifacts/。
- 交付 TASK_ID、RUN_ID、结果路径及主要限制。不自动上传证据、提交 Git、清理历史 Run 或启动浏览器。
