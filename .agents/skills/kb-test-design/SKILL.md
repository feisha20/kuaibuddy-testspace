# KuaiBuddy 测试资产设计

读取仓库 AGENTS.md、docs/project.md、docs/knowledge.md 及相关 tasks/、tests/。本技能只组织项目资产，不复制全局需求分析或外部平台技能。

1. 检索已有目标、场景和数据，优先复用任务和用例编号；新的长期目标才创建新任务。
2. 将正式需求映射为可核对断言。对话场景按实际需求考虑单轮、多轮、完成状态和工具影响；未约定能力列为待确认。
3. 使用 tasks/_template.md 和 tests/cases/_template.md，引用正式资料版本与条目；缺少依据的用例保持草案。
4. 覆盖矩阵、草稿及一次性分析放当前 Run 的 artifacts/ 或 .runtime/scratch/；确认后再沉淀长期资产。用户已明确要求创建资产时按授权直接完成。
5. 交付时说明复用资产、覆盖范围和缺口，维护任务、用例及数据间的引用，不将设计完成写成测试通过。

本技能不授权连接环境、启动浏览器或写入外部系统。按需使用本机已有专业工具，不假设同事已安装，也不复制其实现。
