# TASK-004：生产环境指定周期对话质量分析

## 目标与范围
通过 kuaibuddy-staff 只读获取指定日期范围内生产新建会话及消息，整理有证据的 badcase 与待核实问题。每次复用本任务时重新核实查询授权；日期范围、时区、筛选条件及结果保存于独立 Run，不进入任务定义。

## 前置条件与依据
用户明确生产只读查询授权；有效生产 Staff Key；使用全局 kuaibuddy-staff 技能。正式业务规则缺失时只核查可观察问题，不判断业务准确性。

## 步骤与验收
1. 建立独立 Run，记录环境、日期时区、完整 Git 提交和工作树状态。
2. 按创建日期完整分页获取会话，逐会话获取完整分页消息，先落盘再分析。
3. 核对用户目标、assistant 与工具证据，记录会话、消息和运行标识。
4. 交付清单，分别列出事实、推断、缺失证据与通过／失败／阻塞／未执行情况。

## 限制
创建日期筛选不覆盖此前创建但当天继续交流的会话；不据只读消息断言后台根因或生产可复现。不自动创建缺陷，不启动浏览器，不提交或推送 Git。
