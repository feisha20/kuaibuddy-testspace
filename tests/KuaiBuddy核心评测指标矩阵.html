Prompt Cache 量化口径与 4 项门禁指标

Langfuse GENERATION 节点中 total = input + input_cached_tokens + output + output_reasoning_tokens，其中 input 为未命中缓存的新增输入 Token。

total_input_tokens = input + input_cached_tokens
cache_hit_rate = input_cached_tokens / (input + input_cached_tokens) × 100%
prefix_stability = first_diff_char(R1.input, R2.input) ≥ sys_prompt_length
  • CACHE-001（多 MCP 连续 3 轮）：R2 ≥ 90%、R3 ≥ 90%，且 System Prompt 前缀 100% 一致。
  • CACHE-002（无 MCP 对照基线）：R2 ≥ 90%、R3 ≥ 95%（同步校验跨模型差异）。
  • CACHE-003（短时跨会话 S1 复用）：60 秒内新开会话首轮即复用，S1 ≥ 60%。
  • CACHE-004（单轮多步工具推理）：Step2 及后续步骤稳定在 85%~99%，禁止任何一步跌破 10%（雪崩）。

AgentScope / 新功能更新导致缓存下降的 5 大排查探针

1. System Prompt 拼接顺序非确定性（已实测导致暴跌至 5.50%）
真实案例：PersonalMcpRuntime.attach 曾并发执行并按完成顺序拼接「个人 MCP 使用状态」，导致生产 RUN 85d98b 在第 4929 / 106662 字符处连接器 #14 与 #13 颠倒，R2 命中率仅 5.50%；固定排序后预生产升至 96.80%。
检测方法：通过 Langfuse io 字段拉取 R1 vs R2 的 input，执行逐字符 Prefix Diff，若 first_diff_char < 10000（处于 System Prompt 区）即直接定位前缀污染源。
2. AgentScope Memory / Compaction 过频修改前缀（commit eb3bf3c / 0606280）
框架升级若开启频繁的 Memory Consolidation（曾因间隔过短导致 Cache Miss，后延长至 3 小时 eb3bf3c）或按消息条数粗暴触发 CompactionConfig（0606280 已默认关闭），会改动早期历史消息，导致 KV Cache 全段作废。
3. 长期记忆索引注入与动态 ContextSource 时机
beta 新增公司成员长期记忆（9f5961d）：设计为仅在装配期写入快照（## 长期记忆索引），本轮调用 memory_save 不刷新当前轮次提示词；若框架更新改为每步动态刷新，将直接打碎同轮多步推理缓存。须由 CACHE-005 护栏拦截。
4. Tool Schema / Skill 注册顺序与 reset_equipped_tools
OpenAI / DeepSeek / Kimi 协议中 Tools 定义通常置于缓存前缀最前方；若 AgentScope 更新改变了工具序列化顺序（如 HashSet 遍历替代 LinkedHashMap）或中途无序增删工具定义，会导致首步即失效。
5. 模型路由切流与底层分块粒度差异
ModelSelector 异常冷却单向切换备用模型（K-002）会立即重置对应模型侧 KV Cache；此外不同模型命中粒度不同（实测 Kimi 2.8 preview 778f97 4/4 全过，DeepSeek v4.1 flash b7bd9b 在 TC-02 R3 稳定 26,880 命中但未命中新增 1,614 tokens）。

Langfuse 缓存命中率 + System Prompt 前缀 Diff 自动化检测脚本

python3 - <<'PY'
import os, sys, json, urllib.request, urllib.parse, base64
sys.path.insert(0, '.agents/skills/kb-bug-analyse/scripts')
import local_config

local_config.load_local_config()
host = os.environ['KB_LANGFUSE_PRD_URL'].rstrip('/')
auth = base64.b64encode(f"{os.environ['KB_LANGFUSE_PRD_PUBLIC_KEY']}:{os.environ['KB_LANGFUSE_PRD_SECRET_KEY']}".encode()).decode()

def inspect_run(label, run_id):
    flt = json.dumps([{'type': 'stringObject', 'column': 'metadata', 'key': 'run_id', 'operator': '=', 'value': run_id}])
    url = f'{host}/api/public/v2/observations?fields=core,usage,io&filter={urllib.parse.quote(flt)}'
    with urllib.request.urlopen(urllib.request.Request(url, headers={'Authorization': f'Basic {auth}'}), timeout=15) as resp:
        data = json.loads(resp.read().decode())
    gens = sorted([o for o in data.get('data', []) if o.get('type') == 'GENERATION'], key=lambda x: x.get('startTime', ''))
    step1_input = None
    for idx, o in enumerate(gens, 1):
        u = o.get('usageDetails') or o.get('usage') or {}
        inp, cached = u.get('input', 0), u.get('input_cached_tokens', 0)
        tot_in = inp + cached
        rate = (cached / tot_in * 100) if tot_in else 0.0
        print(f'{label} Step{idx}: input={inp} cached={cached} total_in={tot_in} hit_rate={rate:.2f}%')
        if idx == 1 and o.get('input'):
            step1_input = json.dumps(o['input'], ensure_ascii=False)
    return step1_input
