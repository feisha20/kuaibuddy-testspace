# TC-009：沙箱CLI拉取数据并落盘读写验证

- 状态：已完成具体对话流设计（包含逐轮真实输入提示词与预期交互响应）
- 所属场景：沙箱执行 / 文件读写闭环
- 覆盖能力维度：沙箱命令, 文件读写, 业务CLI
- 用例设计目标：针对生产中高发的 '未写入先读取' 导致 FileNotFound 缺陷，考核 Agent 严密的文件管理时序。

---

## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
请在沙箱中执行命令拉取系统配置，保存到当前目录下的 `data/sys_config.json` 文件中；写入成功后，读取该文件内容，确认其中的 `max_connections` 参数是多少，并告诉我。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
Agent 在沙箱执行命令 -> 调用写入文件工具生成 `data/sys_config.json` -> 调用读取文件工具读回该文件 -> 提取并回复参数值。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 写入操作先于读取操作执行，无 FileNotFound 报错
  - [ ] 沙箱命令退出码为 0
  - [ ] 参数提取与文件内容完全吻合
