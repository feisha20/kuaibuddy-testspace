- **状态**：已就绪（面向人工测试人员在浏览器工作台逐项执行，也可直接拆分录入禅道）
- **所属模块**：KuaiBuddy 工作台核心功能（对话 / 运行控制 / 缓存核验 / 技能与沙箱 / 联网 / 生图 / 定时任务 / 长期记忆 / 积分）

## 一、测试前置准备（开始前核对）

1. **环境与浏览器**：使用 Chrome / Edge 最新版打开目标环境工作台地址（预生产：`https://test-kuaibuddy.dingningtalk.com/`；测试/生产以本次发版通知为准），使用已获授权的测试账号登录。
2. **账号状态核对**：
   - 点击左下角账户头像 → 点击「积分」进入「积分中心」，确认当前**积分余额 > 0**，并**记录初始积分余额**；
   - 点击左下角账户头像 → 点击第一项「长期记忆」，确认当前记忆条数未满上限（`< 100`）；
   - 在对话输入框中键入 `/` 确认当前账号下至少有 **1 个中文名称的只读技能**（记录该技能名，记为 `<中文技能名>`，用于 `MAN-004`）。
3. **辅助观测准备（仅 `MAN-003`、`MAN-004`、`MAN-007` 辅助核对项需要）**：具备目标环境对应的 Langfuse Web 后台访问权限（生产/预生产为 `prd`，测试环境为 `test`）；如测试人员无权访问，可记录会话链接/时间点交由研发协助核对，对应辅助项标为「待核对/阻塞」。

- **优先级**：P0
- **前置条件**：目标环境已上线长期记忆功能，当前账号记忆条数 `< 100`。
