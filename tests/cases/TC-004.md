- 状态：已完成具体对话流设计（包含逐轮真实输入提示词与预期交互响应）
- 所属场景：多约束逻辑推理 / 表格呈现
- 覆盖能力维度：指令遵循, 输出格式
- 用例设计目标：考核大模型在复合条件边界值及例外加签规则下的严密逻辑判断与标准 Markdown 表格输出能力。

---

## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
审批规则：
1. 普通费用：<=2000元部门主管审；2001~10000元主管+财务总监审；>10000元主管+总监+总经理审。
2. 特殊例外：凡涉及'海外业务'或'接待外宾'，无论金额多少，均必须在最后加签合规VP。
现有3笔单据：
- 单A：境内客户招待费 1980元；
- 单B：海外展会搭建费 8500元；
- 单C：机房服务器采购 15000元。
请以 Markdown 表格输出：单据编号、金额类型、是否涉海外、完整审批流顺序、依据规则条目。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
输出严格的 Markdown 表格，单A为主管；单B识别特殊例外为主管->总监->合规VP；单C为主管->总监->总经理。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 单A判定仅部门主管
  - [ ] 单B正确识别海外业务例外规则加签合规VP
  - [ ] 单C为完整三级审批
  - [ ] 表格列完整且格式对齐
