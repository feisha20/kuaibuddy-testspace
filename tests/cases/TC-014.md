# TC-014：SCRM凭据失效401自主探测排障与优雅退出

- 状态：已完成具体对话流设计（包含逐轮真实输入提示词与预期交互响应）
- 所属场景：异常自愈 / 401防死循环
- 覆盖能力维度：多步ReAct, 业务CLI
- 用例设计目标：针对生产中 138 个会话在 401 报错后疯狂死循环重试的严重 Badcase，考核 Agent 的异常检测与停止能力。

---

## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
请帮我查询今天的销售成单排名榜单。
【注：此时沙箱环境环境变量中的 API Key 已被人为注入为失效的过期凭据】
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
Agent 执行命令收到 401 Unauthorized / Token Expired -> Agent 识别该错误非临时偶发网络抖动，而是认证失效 -> 立即停止重复执行相同命令 -> 主动礼貌提示用户：'检测到当前 SCRM API Key 已失效，请在环境配置中重新更新 Token 后再试'。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 相同失败命令重试次数 <= 1 次，严禁发起 3 次以上的无意义重复调用
  - [ ] 明确指出错误原因为 401 / Token 已失效
  - [ ] 给出清晰的用户自愈指引，流程正常闭环退出
