# TC-021：多轮模糊情绪客诉意图主动澄清与精准排障

- 状态：已完成具体对话流设计（包含逐轮真实输入提示词与预期交互响应）
- 所属场景：多轮意图澄清 / 主动排障
- 覆盖能力维度：多步ReAct, 技能脚本, 业务CLI, 多轮, 意图理解
- 用例设计目标：针对用户带情绪发牢骚、未提供有效故障信息的对话，考核 Agent 主动引导澄清，而非盲目调错工具。

---

## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
你们系统怎么又登不进去了？每次到月底就崩，到底能不能用啊？！
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
安抚情绪，不盲目报错，主动澄清：1. 确认具体是哪套系统（管理后台、客服工作台还是手机 App）；2. 询问登录报错提示或错误码（如密码错、提示无权限还是验证码收不到）。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 未盲目调用错误工具发起无效请求
  - [ ] 语气沉稳温和，给出清晰的 2~3 个澄清选项

### 第 2 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
就是网页端的客服工作台，点登录提示什么 'Token expired (2008)'。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
准确识别出错误码 2008（Token 过期 / Staff Key 失效），自主查询用户账号状态或连通性，给出明确结论：'您的会话令牌已过期，请点击右上方重新刷新登录态或重新获取授权'。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 精准匹配 2008 错误码为 Token 过期
  - [ ] 给出针对性自愈解决方案
  - [ ] 闭环解决用户诉求
