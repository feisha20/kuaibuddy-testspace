## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
本地有一个 `local_orders_20261110.csv` 记录了 50 笔交易。请帮我与远程 SCRM 系统的实际订单对账：
1. 分页查出远程全部订单；
2. 找出本地有但远程漏掉的单子；
3. 找出两边金额不一致的单子；
4. 输出一份 Markdown 对账报告 `diff_report.md`，写明漏单号与差异金额。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
自主分解为 4 个子步骤执行：读取本地文件 -> 分页拉取远程 -> 编写比对逻辑 -> 输出差异文件，并在对话中汇报核心差异概况。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 自主完成多步组合，无需用户中间指导
  - [ ] 准确找出预置的漏单项与金额差异项
  - [ ] 生成完整的 diff_report.md 报告
