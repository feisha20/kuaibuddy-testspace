# TC-017：客户关怀全周期待办事项拆解与状态原子更新

- 状态：已完成具体对话流设计（包含逐轮真实输入提示词与预期交互响应）
- 所属场景：待办清单流转 / 状态原子维护
- 覆盖能力维度：待办计划, 文件读写, 文件入库, 定时任务
- 用例设计目标：针对生产 75 次更新待办失败，考核待办项的新建、查询、指定 ID 状态变更（pending->completed）的原子性。

---

## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
我们刚签约了重要客户「华东医疗集团」，请帮我制定一份 14 天交付关怀待办计划，拆解为 4 个具体阶段的任务清单并录入系统待办。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
调用待办管理工具创建 4 项待办任务，返回各任务的唯一 taskId 与待办列表。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 调用待办创建工具成功
  - [ ] 4 个任务状态均为 pending
  - [ ] 返回可识别的 taskId 数组

### 第 2 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
第 1 阶段「系统初始化配置与权限分配」刚才工程师已经确认完成了。请把这一项待办标记为已完成，并告诉我整体进度是多少。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
定位第 1 项的 taskId，调用待办更新工具将其原子更新为 completed，其余 3 项保持 pending，计算进度为 25.0%。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 准确更新指定 taskId，无状态覆盖其他待办项
  - [ ] 更新待办工具调用结果为 success
  - [ ] 准确计算并返回已完成比例
