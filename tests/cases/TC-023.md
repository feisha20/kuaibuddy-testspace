```text

```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
生成包含 3 个分镜的脚本，调用 VideoTool 渲染，返回包含 videoId='vid_20261111_001' 的视频消息卡片，前端可内嵌播放。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 生成有效 videoId
  - [ ] 符合视频消息共享协议
  - [ ] 会话中呈现内嵌播放组件

### 第 2 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
我看了一下第一版视频，第 2 个分镜画面有些暗，把背景调整为更明亮的科技蓝办公区，字幕字体加大一号，在此基础上直接续聊更新生成新版视频。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
续聊中回读上一轮 videoId_001 的分镜配置，仅修改第 2 分镜参数，重新提交渲染生成新视频 videoId_002，两版视频在历史记录中均可回放（验证 beta 视频续聊改动）。

#### 3. 逐项明确断言与判断标准 (Assertions)

  - [ ] 仅对第 2 分镜进行增量更新
  - [ ] 生成新的视频卡片，新旧视频均保留有效播放地址
