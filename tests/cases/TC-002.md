# TC-002：严格无代码块纯JSON格式与装配清单抽取

- 状态：已完成具体对话流设计（包含逐轮真实输入提示词与预期交互响应）
- 所属场景：严格指令遵循 / 格式约束
- 覆盖能力维度：指令遵循, 输出格式, 工具装配
- 用例设计目标：检验 Agent 面对严格输出限制时，能否做到 0 闲聊、0 代码块包裹、100% 符合 JSON 反序列化要求。

---

## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
请列出当前会话中你装配的所有可用工具。要求：
1. 必须且只能输出合法的 JSON 数组，不能有任何其他文字说明；
2. 严禁使用 ```json 或 ``` 代码块包裹；
3. 每个对象必须严格包含 4 个字段："tool_name"(字符串), "description"(字符串), "timeout_seconds"(数字), "requires_auth"(布尔值)；
4. 首字符必须是 [，末字符必须是 ]。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
直接返回原生 JSON 字符串，首尾为 [ 和 ]，使用 json.loads() 可直接无异常解析，每个对象具有指定 4 个 key。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] json.loads(response) 解析成功，无 SyntaxError
  - [ ] 首字符为 '['，末尾字符为 ']'
  - [ ] 字段列表完全匹配 tool_name, description, timeout_seconds, requires_auth
  - [ ] 无任何前置引导语（如“好的，这是你要的JSON：”）或后置解释
