# TC-018：高频同义客诉语义聚类去重与Top5提取

- 状态：已完成具体对话流设计（包含逐轮真实输入提示词与预期交互响应）
- 所属场景：长文本处理 / 历史同义去重
- 覆盖能力维度：文件读写, 定时任务, 历史去重
- 用例设计目标：解决客服场景中访客高频重复刷屏（如'没人吗'、'催一下'、'人呢'）导致客诉统计失真的问题。

---

## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
这里有一份包含 200 条昨日访客负面反馈的原始记录 `complaints_raw.txt`。里面有大量用户用不同的话表达同一个意思（比如'催进度'、'怎么还没好'、'什么时候完成'其实都是进度催促）。请对这些历史反馈进行语义去重和聚类，输出排重后的 Top 5 核心客诉分类及其聚合频次统计表。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
读取文件 -> 实施语义聚类/去重逻辑 -> 将同义表达归并到统一诉求标签 -> 输出 Top 5 统计表与改进建议。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 同义刷屏话术被正确聚合为单项统计
  - [ ] Top 5 类别边界清晰，无相互重叠
  - [ ] 频次总和逻辑自洽
