# TC-001：每日客服经营指标早报定时生成

- 状态：已完成具体对话流设计（包含逐轮真实输入提示词与预期交互响应）
- 所属场景：定时任务 / 纯文本日报
- 覆盖能力维度：纯文本生成, 定时任务
- 用例设计目标：检验 Agent 识别定时周期参数，并在触发时稳定输出结构化纯文本早报，不调用无关外部工具。

---

## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
请帮我设置一个每天早上 08:30 自动执行的定时任务：标题叫「客服每日经营早报」。任务内容是汇总昨天全渠道客服的接待总量、平均首次响应时长、好评率以及排队流失率。请以排版整齐的纯文本格式生成日报，不要调用无关的修改或生图工具。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
调用 schedule 工具，参数包含 title='客服每日经营早报'，rrule='FREQ=DAILY;BYHOUR=8;BYMINUTE=30'。返回创建成功的调度任务 ID 与下次执行时间。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 识别定时频率为每日 08:30
  - [ ] 调用 ScheduleTool 成功
  - [ ] 返回明确的调度确认信息

### 第 2 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
【定时触发模拟执行】：现在到了早上 08:30，请立即输出昨天的「客服每日经营早报」。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
以清晰的纯文本（分段、emoji 或列表符）输出指标早报，包含接待总量、首响、好评率等四大板块，无 Markdown 表格错乱，无多余未授权工具调用。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 无工具调用失败异常
  - [ ] 包含四大核心指标结构
  - [ ] 纯文本格式整洁、语气专业
