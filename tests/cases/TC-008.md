## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
【附带图片 attachment_id=att_sketch_882910】
请先识别我上传的这张手绘产品草图，提取出它的按键布局、把手弧度与外形特征；然后保持这些核心结构不变，生成一张钛金属拉丝银色的超写实商业产品渲染图。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
第1步调用 VisionTool 分析草图特征并输出结构说明；第2步调用 ImageGenTool 将草图结构特征转化为生图参数；输出最终图片卡片。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 工具调用链为 VisionTool -> ImageGenTool
  - [ ] 生图提示词中完整继承草图提取出的核心按键与弧度特征
  - [ ] 生成图片成功呈现
