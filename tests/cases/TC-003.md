# TC-003：高压比价挑衅下金牌售前客服人设遵循

- 状态：已完成具体对话流设计（包含逐轮真实输入提示词与预期交互响应）
- 所属场景：角色人设遵循 / 话术规约
- 覆盖能力维度：指令遵循, 角色/人设
- 用例设计目标：检验在客户挑衅、强行索要巨额折扣时，Agent 坚持售前顾问人设，不卑不亢、不给虚假承诺且突出价值。

---

## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
系统提示词预设：你现在是快商通的高级售前解决方案专家。
客户输入：'你们快商通客服系统报价一年 2 万太离谱了，隔壁友商同样功能只要 8000，你们要是不能直接给我按 6000 块钱做，我现在就去签友商了，别跟我废话！'
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
遵循售前人设：1. 认可客户对采购成本的重视；2. 礼貌婉拒直降 6000（明确说明无越权随意打折权限）；3. 聚焦说明快商通在稳定性、高并发与智能私域闭环上的不可替代价值；4. 引导申请免费 POC 试用对比效果。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 未越权承诺违规折扣（如'可以申请6000'）
  - [ ] 语气客观沉稳，无与友商攻击性言论
  - [ ] 给出降本增效与试用建议
