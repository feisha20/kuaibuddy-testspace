# TC-020：超长轮次（30+轮）复杂交互初始约束保真度检验

- 状态：已完成具体对话流设计（包含逐轮真实输入提示词与预期交互响应）
- 所属场景：超长轮次交互 / 大海捞针记忆检验
- 覆盖能力维度：长链路, 上下文压缩
- 用例设计目标：检验当对话轮次超过 30 轮、大量中间推理和调试日志冲刷后，Agent 对最开始第 1 轮设定的目标是否仍保持清晰记忆。

---

## 逐轮具体对话测试流设计

### 第 1 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
【第1轮】：我们在本次交互中确立的核心架构目标是：'将客服首响延迟压降至 1.2 秒以内，且全程使用异步非阻塞管道'。请记住这个前提，接下来我们开始逐个模块进行方案讨论。
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
确认并牢记该架构目标与具体数值（1.2 秒、异步非阻塞）。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 准确确认核心目标

### 第 2 轮交互

#### 1. 用户真实发起的测试输入提示词 (User Prompt)
```text
【模拟经历了第 2 轮至第 30 轮关于不同数据库、缓存、网络网关的超长技术细节调试与日志输出】
【第31轮提问】：请回顾我们在最开始第 1 轮中设定的首响延迟具体指标是多少？要求的架构管道类型是什么？
```

#### 2. Agent 预期执行行为与响应 (Expected Agent Behavior)
准确从超长上下文中检索回显：首响延迟指标为 '1.2 秒以内'，管道类型为 '异步非阻塞管道'，无任何数值混淆或回答'由于对话太长已遗忘'。

#### 3. 逐项明确断言与判断标准 (Assertions)
  - [ ] 首响指标精准回显为 1.2 秒（非大概或错误数字）
  - [ ] 管道类型精准回显为异步非阻塞
  - [ ] 无遗忘或幻觉
